## 完整汇总 Prompt 模板

调用方按以下固定顺序组装 HTTP 请求中的 `prompt` 字段：

```text
{{主体模板}}

【用户补充的视觉要求】
{{supplementalPrompt}}

{{articleContextBlock}}
```

其中 `{{主体模板}}` 必须是上面十套模板之一；`{{supplementalPrompt}}` 为空时移除整个“用户补充的视觉要求”块；`{{articleContextBlock}}` 只有用户主动勾选“将标题和摘要作为视觉参考”时才替换为以下内容，否则整体移除：

```text
以下文章信息仅用于理解主题、情绪和视觉隐喻；不得复述、排版、引用或在图片中模拟其文字。

文章标题：{{title}}
文章摘要：{{digest}}
```

标题与摘要默认不勾选。即使勾选，也必须保留主体模板中的无文字约束。
