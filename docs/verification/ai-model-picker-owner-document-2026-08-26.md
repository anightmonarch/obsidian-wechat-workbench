# 模型下拉浮层独立设置窗口验证（2026-08-26）

## 根因证据

- 修复前在隔离 Vault 的真实独立设置窗口点击模型箭头后，按钮 `aria-expanded` 变为 `true`，但该设置窗口内模型菜单数量仍为 `0`。
- 插件模块的全局 `document` 属于 Obsidian 主窗口；旧实现把浮层追加到主窗口 `document.body`，因此设置窗口内不可见。

## 修复验证

- 新增 iframe 独立文档回归测试：修复前失败，修复后菜单挂载到箭头按钮的 `ownerDocument`，主测试文档中不存在误挂载菜单。
- 菜单创建、定位、窗口滚动/缩放监听和外部点击监听均使用所属文档及其 `win`。
- 重新构建并同步到 `$HOME/workspace/Github/wechat-workbench-test-vault` 后，在 Obsidian 1.13.7 独立设置窗口点击箭头，辅助功能树出现 `列表框` 和 3 个模型选项；列表不再落到主窗口背后。
- 验证过程未读取、输出或记录 API Key 明文。

## 列表内部滚动修复

- 根因是所属窗口注册了捕获阶段的 `scroll` 监听，模型菜单自身滚动时同样触发该监听并关闭浮层。
- 现在菜单自身作为滚动目标时保持展开；设置页外层滚动、窗口缩放、点击外部、切换模式或供应商仍会关闭浮层。
- 回归测试验证：列表内部滚动后菜单仍在 DOM 中，并可选择最后一个模型；窗口外层滚动仍会关闭菜单。
